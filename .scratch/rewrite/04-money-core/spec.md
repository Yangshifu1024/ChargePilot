# 阶段 04 · 资金主链路

Status: ready-for-agent

## Problem Statement

核心业务缺失：无法下单、无法充电计费、无法结算开票、无法退款。这是整个重写中价值最高、风险最高的阶段——旧版全部资金语义（幂等、锁序、快照冻结）必须等价迁移，同时链路要按事件驱动状态机重构。

## Solution

交付 charging（按状态机新设计）/ order / settlement / wallet / payment / card 六域，含微信支付 APIv3 自研封装与充电状态机的事件驱动实现；资金纯函数通过新旧差分对照验收。

## User Stories

1. 作为充电用户，我想扫码解析设备与端口并发起订单（余额不足则引导充值），所以能开始充电。
2. 作为充电用户，我想用模拟支付完成支付后订单自动启动充电，所以全流程无需真实商户。
3. 作为充电用户，我想在充电中看到实时电量、功率与预估费用（秒级内刷新），所以费用透明。
4. 作为充电用户，我想手动停止充电，也想让余额/时长耗尽时自动停机，所以不会意外欠费。
5. 作为充电用户，充电结束后我想看到账单明细（时段拆分、电费/服务费），所以费用可核对。
6. 作为充电用户，我想申请退款（余额或订单预付）并看到退款进度，所以资金有出路。
7. 作为充电用户，我想申请开票并在审核通过后获取，所以能报销。
8. 作为刷卡用户，我想在线卡在桩上刷卡即充电（平台校验余额并扣款），所以不用手机也能用。
9. 作为运营人员，我想处理人工退款申请（审核/执行/驳回），所以异常订单有处理通道。
10. 作为运营人员，我想核实计量争议（仪表审核）并修正账单，所以计量纠纷有依据。
11. 作为运营人员，我想手动结算异常订单，所以卡单有出口。
12. 作为运营人员，我想查看钱包流水与风控冻结/解冻，所以资金操作可追溯。
13. 作为开发者，我想支付回调幂等（重放不重复入账）且回调验签失败被拒，所以资金入口可信。

## Implementation Decisions

- **状态机落地**（本阶段核心，依 [ADR 002](../../../docs/adr/002-event-driven-state-machine.md) 与阶段 00 定义）：支付成功/刷卡准入 → `paid`（同事务：订单状态 + 启动意图 + 事件）→ 投递器驱动启动（写命令 + 预留端口）→ 设备回执 `starting→charging` → 用户停止/自动停机 `stopping`（同事务冻结计费截止快照）→ 结束回执 `billing`（计量分段确认）→ 计费批次 `settled` → 退款意图 `refunded`；每步超时出口由兜底扫描接管。
- **计费快照冻结**：下单时冻结计费方案快照，停止时冻结计量截止点；计费只读快照——两处冻结语义照搬旧版，属红线层。
- **幂等表清单照搬**：启动/结束/费用回执、支付回调幂等（30 天）、卡操作 `event_id`、退款成功回执；处理器幂等评审为固定检查项。
- **微信支付封装**（自研 APIv3）：请求签名（SHA256withRSA）、平台证书下载与应答/通知验签、回调 AES-256-GCM 解密、敏感信息加密；三模式 `disabled / simulation / wechat_direct`；退款开放状态集合原样透传。
- **卡域**：在线卡余额校验、刷卡扣款事务（拒绝码 2009 语义）、累计时长、续购。
- **锁序与并发**：同订单串行（状态机天然串行）、钱包账户行锁、`SKIP LOCKED` 批次领取照搬；全局无热点（号段 ID 已消唯一锁点）。
- 优惠券抵扣点留接口缝（规则在阶段 05 接入），本阶段计价路径不含券。

## Testing Decisions

- **差分对照（辅缝 2）**：计费纯函数（分时段拆分、decimal 取整、分段计量）与退款计算，用旧版同输入批跑比对，覆盖取整边界与 `StringFixed(6)` 输出。
- **主缝真库集成**：全链路（下单→启动→充电→停止→结算→退款）；每条幂等表的重放拒绝；同订单并发操作串行化；钱包行锁并发扣款；`SKIP LOCKED` 批次不重复领取。
- **状态机**：每个合法迁移一条集成路径；非法迁移类型层拒绝；超时出口由注入时钟推进验证兜底接管。
- **微信封装**：官方测试向量（验签/解密）+ simulation 模式全流程；真实商户联调在上线前清单。
- 好测试：断言 HTTP 响应与库中资金行，不断言内部函数被调用。

## Out of Scope

券抵扣与活动赠券（阶段 05）；监管报送（未装配）；真实微信商户联调（上线前清单）；小程序端改动（阶段 09 回归）。

## Further Notes

本阶段允许超支：宁可拖期不可弱化幂等与差分验收。发现旧版语义存疑处（如取整边界），以差分结果为准并记入 ADR 修订记录。
